# Can I Take This?

A travel utility for checking whether an item is allowed in cabin or checked baggage based on the airline, departure airport, and destination.

This repository currently contains the project foundation only. It does not include live travel rules, external integrations, authentication, or database logic.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Validation

```bash
npm run lint
npm run build
```

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- shadcn/ui
- Lucide React
- ESLint
